# Merhaba — 한국인을 위한 튀르키예어

한국어 화자에게 맞춘 튀르키예어(터키어) 학습 웹앱입니다. 휴대폰 브라우저에 최적화되어 있고, 설치 없이 바로 쓸 수 있어요.

**바로 사용하기 → https://dubuzzang.github.io/turkish-for-koreans/**

## 왜 한국인에게 맞춤인가

튀르키예어는 한국어와 놀랄 만큼 닮았습니다. 이 앱은 그 공통점을 학습의 지렛대로 씁니다.

| 튀르키예어 | 한국어 | 예 |
|---|---|---|
| 주어-목적어-동사 어순 | 같음 | Ben elma yiyorum = 나는 사과를 먹어요 |
| 조사를 붙이는 교착어 | 같음 | ev**de** = 집**에서**, okul**a** = 학교**에** |
| 모음조화 | '잡아/먹어'의 아/어 | ev**ler** / kitap**lar** |
| 존댓말 sen/siz | 반말/존댓말 | Nasılsın? / Nasılsınız? |
| 이·그·저 3단계 지시어 | 같음 | bu · şu · o |
| 외가·친가 구분 호칭 | 같음 | anneanne(외할머니) / babaanne(친할머니) |
| ı, ö, ü 모음 | 으, 외, 위 | kız, göz, gül |

## 학습 효과를 위한 설계

- **인출 연습 중심 레슨**: 짧게 보여 주고 곧바로 떠올리게 합니다(객관식 → 짝 맞추기 → 문장 조립 → 직접 쓰기).
- **오답 재출제**: 틀린 문제는 레슨 끝에 다시 나오고, 틀린 단어는 복습 카드에서 더 일찍 돌아옵니다.
- **간격 반복(FSRS-5)**: 최신 기억 모델로 기억률 90%를 유지하도록 다음 복습일을 계산합니다. 인식(튀르키예어→뜻)이 익숙해지면 산출(뜻→튀르키예어) 카드가 열립니다.
- **한국인이 헷갈리는 발음 훈련**: f/p, v/b, z/c, s/ş, ı/i, o/ö, u/ü, r/l 최소대립쌍 듣기 퀴즈.
- **한글 발음 표기(선택)**: 입문 단계의 읽기 부담을 줄이고, 익숙해지면 끌 수 있습니다.
- **약점 공략**: 자주 틀린 단어·문장·문법만 모아 다시 연습합니다.
- **매일 습관**: 하루 목표 XP, 연속 학습일, 오늘의 표현.

## 구성

- **0단원 발음·알파벳** — 29글자, 한국어 대응 소리, 주의할 글자, 발음 규칙
- **학습 경로** — 1단원 첫 만남 · 2단원 나와 가족 · 3단원 있다·없다/어디에 · 4단원 숫자와 쇼핑 · 5단원 식당과 카페 (단원은 계속 추가)
- **복습** — FSRS 플래시카드, 주제별 새 단어 늘리기
- **연습** — 단어 퀴즈, 듣기 훈련, 문장 조립, 쓰기, 받아쓰기, 발음 구분, 약점 공략
- **단어장** — 예문·메모가 있는 핵심 단어 약 900개, 검색과 주제별 보기

## 사용 팁

- 발음은 기기의 음성 합성(TTS)을 씁니다. 튀르키예어 음성이 없으면 앱의 **설정 → 튀르키예어 음성 설치 방법**을 따라 설치하세요.
- 학습 기록은 브라우저(localStorage)에만 저장됩니다. 기기를 바꿀 때는 **설정 → 백업 내보내기/불러오기**를 쓰세요.

## 개발

빌드 도구 없이 순수 HTML·CSS·JavaScript(ES 모듈)로 만들었습니다.

```bash
npm test          # 핵심 로직·데이터 테스트 (Node 20+)
npm run serve     # http://localhost:5173 (Python 필요)
```

```
index.html, css/app.css
js/app.js               라우터·앱 셸
js/core/                채점(tr), 한글 표기(hangul), FSRS(srs), 덱(deck), 저장(store), 음성(tts), UI
js/data/                단어(vocab-*.js), 커리큘럼, 알파벳, 오늘의 표현
js/views/               화면(홈·학습·레슨·복습·연습·단어장·알파벳·설정)
tests/                  node:test 테스트
```

`main` 브랜치에 푸시하면 GitHub Actions가 테스트 후 GitHub Pages로 배포합니다. 버전별 변경 사항은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.
